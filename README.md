# ⛓️ JobChain – Blockchain-Based Job Marketplace

A decentralized job marketplace built using blockchain technology to provide a transparent, secure, and reliable platform for job seekers and recruiters.

## 🚀 Project Overview

JobChain is a blockchain-based job marketplace that connects recruiters and job seekers. It uses **Hyperledger Fabric** to maintain transparency and trust in job-related transactions.

The platform allows recruiters to post job opportunities and candidates to explore available jobs and submit applications.

## ✨ Features

- **Dashboard:** View available jobs, submitted applications, and registered companies.
- **Find Jobs:** Browse and search for available job opportunities.
- **Post a Job:** Recruiters can publish new job openings.
- **Applications:** Track submitted job applications.
- **Blockchain Integration:** Uses Hyperledger Fabric for secure and transparent operations.
- **Smart Contracts:** Chaincode manages blockchain-based job marketplace operations.

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/kishita21/JobChain.git
```

### 2. Navigate to the Project

```bash
cd JobChain
```

### 3. Install Frontend Dependencies

```bash
cd frontend
npm install
```

### 4. Start the Frontend

```bash
npm run dev
```

### 5. Backend Setup

Open another terminal:

```bash
cd backend
npm install
```

Start the backend using the script configured in `backend/package.json`.

### 6. Blockchain Setup

Configure the Hyperledger Fabric network and deploy the job marketplace chaincode before running blockchain-integrated operations.

## 🎯 Project Objective

The main objective of JobChain is to develop a decentralized recruitment platform that improves transparency, security, and trust in the traditional job application process.

## 🔮 Future Scope

- User authentication and role-based access.
- Recruiter and candidate profiles.
- Real-time application status updates.
- Blockchain-based verification of job postings.
- Secure candidate credential verification.
